# 手冊 — 日常操作

所有操作都從同一個地方開始：

```bash
cd /home/projects/hermes_experts
./hh
```

---

## 一、新增專家

```
./hh new
```

需要準備的東西：

| 項目 | 怎麼來 |
|---|---|
| 英文代號 | 你自己定（`mpf`、`developer`） |
| 群裡顯示名 | 你自己定（`MPF專家`） |
| 一句話簡介 | 其他專家靠這句判斷「該不該建議找你」 |
| 專長 | 逗號分隔 |
| App ID / Secret | **飛書後台建自建應用**（見下） |

### 飛書那邊要做的五件事（無法自動化）

1. 開放平台 → 建立企業自建應用 → 名稱用你的顯示名
2. 添加「機器人」能力
3. 權限管理 → 加入：
   - `im:message`（收發訊息）
   - `im:chat:readonly`（讀自己所在的群）
4. 事件訂閱 → `im.message.receive_v1` → **長連線**模式
5. 建立版本 → 發布

> 飛書沒有「用 API 建立自建應用」的端點，所以這五步只能人手做。

### 工具會替你做完剩下的

```
建 private/experts/<name>/（expert.yml、SOUL.md、skills/、.env）
生成 service 定義
啟動容器
等 Feishu WebSocket 連線
```

最後畫面會告訴你下一步：**把機器人拉進群**。

---

## 二、建立群

| 步驟 | 誰做 |
|---|---|
| 飛書開群、改名、加你自己 | 你（兩個點擊） |

群本身不需要任何設定。專家的「只被 @ 才回應」是全群生效，不用逐群設定。
想知道「哪個群有哪幾位專家」，跑 `./hh list` —— 它即時問飛書，不靠任何檔案。

---

## 三、把專家拉進群

1. 群設定 → 群組機械人 → 添加機械人 → 搜尋顯示名 → 加入
2. 在群裡打 `@MPF專家 你好` → 它會給你 8 位配對碼
3. `./hh approve <代號>` 貼上配對碼
4. 再 `@` 它一次

**拉進群這件事不需要任何指令** —— 飛書那邊按完就生效。
只有第一次對話要批核（每個專家一次）。

如果之後有新專家加入，想讓**舊專家**也認識它：`./hh refresh`（熱更新，不用重啟）。

---

## 四、教它做事（在群裡講就好）

### 工作範圍

```
你：你負責 MPF 對帳與強積金查詢，不碰程式碼。
```

它會把這段寫進 `private/experts/mpf/expert.yml`，其他專家下次重啟就會看到。
驗證：

```bash
grep summary private/experts/mpf/expert.yml
```

### 做事步驟（技能）

```
你：以後 MPF 對帳照這個流程：先核對供款、再核對收益、最後驗算總額…
```

它會建立 `private/experts/mpf/skills/<主題>/SKILL.md`。

### 密碼（**不要**在群裡貼）

```bash
./hh secret mpf DB_PASSWORD
```

畫面不會顯示輸入內容。檔案在 `private/experts/mpf/.env`（600），
容器會自動重建以載入。

## 五、日常維運

| 想做的事 | 指令 |
|---|---|
| 看所有專家狀態 + 所在群 | `./hh list`（即時查飛書） |
| 體檢 | `./hh doctor` |
| 看日誌 | `./hh logs mpf` |
| 重啟某位 | `./hh restart mpf` |
| 重啟全部 | `./hh restart-all` |
| 讓所有專家認識新成員 | `./hh refresh` |
| 更新框架 | `./hh update` |
| 移除（保留記憶） | `./hh rm mpf` |
| 移除（連記憶刪除） | `./hh rm mpf --purge` |

---

## 六、備份

要備份的是 `private/`，不是 git：

```bash
tar czf hermes-experts-$(date +%F).tar.gz private/
```

裡面有：每位專家的職責、性格、技能、憑證，以及群組對照。
**這個壓縮檔含密碼，不要上傳雲端或 git。**

---

## 七、常見問題

| 症狀 | 原因 | 解法 |
|---|---|---|
| 專家不回應 | 沒被 @ / 容器沒跑 | `./hh doctor`、`./hh logs <name>` |
| 加了權限仍收不到 | 飛書後台沒按「發布版本」 | 重新發布 |
| 舊專家不知道新專家 | 名冊沒熱更新 | `./hh refresh` |
| 容器一直重啟 | 憑證錯 | `./hh logs <name>` 看 401/403 |
| `adapter creation failed` | 映像缺 lark-oapi | `./hh update`（重建映像） |
| 改了 expert.yml 別人不認識 | 名冊沒重生成 | `./hh restart-all` |
